SigmaDrive 0.2.6 두 PC 시험 설치

SigmaDriveSetup-0.2.6.exe (512 KiB) 하나만 새 PC에 복사해 실행합니다.
설치 버튼을 누르면 앱 본체 17,690,474 bytes를 5개의 최대 4 MiB 조각으로 받습니다.
jsDelivr 우선, 일시적 오류만 같은 GitHub 커밋의 보조 경로로 전환합니다.
서명 메타데이터와 조각/완성 파일 SHA256을 검증하며, 중단 후 검증된 조각을 재사용합니다.
필요한 Dokany 드라이버(3개 조각)는 없을 때만 받고 Windows 관리자 승인은 사용자가 합니다.
WebView2가 없으면 Microsoft 공식 설치 프로그램으로 준비합니다.
앱/드라이버의 다운로드 위치나 설치 폴더를 사용자가 선택할 필요가 없습니다.

이 패키지는 시험 최초 설치용입니다. 기존 버전은 안전한 자동 업데이트 연결이 완료되지 않아
직접 덮어쓰기를 거부합니다. 시험 PC는 정상 제거 시 사용자 데이터 삭제를 선택하지 않고
재설치합니다. 이것은 자동 업데이트 검증을 대체하지 않습니다.
로그인과 인증은 본인이 진행합니다. 수신만 하는 PC는 온라인 개인 프로필이 필수가 아닙니다.
제공 PC는 온라인 프로필, 회원 등록, 폴더별 공유, 멤버 초대와 기기 지문 확인/접근 승인이 필요합니다.

검증: 연결 -> 한글/하위 폴더 열기 -> 32 MiB 파일을 수신 PC의 로컬 폴더로 복사 ->
송수신 SHA256 일치 -> 읽기 전용 쓰기 거부 -> 공유 중지 후 새 읽기 거부 -> 재개 ->
접근 회수 후 읽기 거부 -> 드라이브 연결 해제 및 시험 공유 중지.
같은 LAN과 다른 인터넷 회선의 결과는 별도로 기록합니다. 현재 팀 공유는 읽기 전용입니다.
기존 자세한 회원/기기 등록 절차는 clients/0.2.5/windows-amd64/TWO_PC_TEST.txt를 참고하되
설치 단계는 이 작은 설치 파일 안내를 따릅니다.

0.2.6 수정: 느린 원격 읽기의 실제 진행량에 맞춰 Dokany 요청 제한시간을 갱신합니다.
권한 검사와 회수 시 데이터 차단을 유지합니다. 수락된 멤버 초대의 정기 새로고침도 수정했습니다.
