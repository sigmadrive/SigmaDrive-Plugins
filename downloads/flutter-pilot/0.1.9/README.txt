Isolated SigmaDrive Flutter Pilot 0.1.9 (Windows x64).
Install path and data are separate from SigmaDrive. Stable production catalog is unchanged.
The small installer embeds threshold-signed metadata, downloads immutable chunks from jsDelivr with GitHub fallback and verifies wire/decoded/full hashes.
Windows Authenticode signing and Flutter automatic updates are not configured for this pilot.
This publication is not evidence of physical-PC installation, 1 GiB tests or 24-hour continuity.
